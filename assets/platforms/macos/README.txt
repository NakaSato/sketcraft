Install SketCraft

Drag SketCraft.app onto Applications.

Updating an older installation

1. Quit the app.
2. Drag SketCraft.app from this disk image onto Applications and choose Replace.

Some earlier releases were installed as SolveCraft.app. Move that one to the Trash
once SketCraft.app is in Applications, and replace any Dock shortcut with the
old name (open SketCraft.app, then choose Options > Keep in Dock).

Designs saved as .sketcraft or .solvecraft still open, and SketCraft copies
your settings and recovery files from the old SolveCraft folder on its first
launch. New designs are saved as .sc.
