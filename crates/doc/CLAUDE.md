# CLAUDE.md — sketcraft-doc

The document model (layer L2): user and model parameters with expressions, sketches and features
on a parametric timeline, components and occurrences, joints, appearances, configurations, sheet
metal, drawings, and incremental evaluation through the kernel. It also owns the design file
format and its migrations. Depends on `geom`, `sketch`, `kernel`, `render`, `profile` and
`derive`. See the root CLAUDE.md.

## Commands

```sh
cargo test -p sketcraft-doc                       # all unit tests (builds the kernel: solidcore)
cargo test -p sketcraft-doc --lib format          # format/migration tests
cargo test -p sketcraft-doc feature_walk          # golden walk records
FEATURE_WALK_BLESS=1 cargo test -p sketcraft-doc feature_walk   # re-record an intended change
cargo check -p sketcraft-doc --target wasm32-unknown-unknown
# Ignored microbenchmarks (no timing assertion):
cargo test --release -p sketcraft-doc --lib benchmark_placements_walk -- --ignored --nocapture
```

Tests are unit tests only (`src/tests.rs`, `src/*_tests.rs`). There is no `tests/` directory.

## Layout

- `src/lib.rs`: module list and re-exports. Re-exports the kernel and sketch crates as
  `sketcraft_doc::kernel` and `sketcraft_doc::sketch`.
- `src/document.rs`: `Document`, `FeatureKind` (every feature variant) and the caps
  (`MAX_FEATURES`, `MAX_PARAMS`, …).
- `src/eval.rs` (largest) and `eval_*.rs`: timeline evaluation with the kernel. `EvalCache` and
  `KeptResults` make it incremental. `model_cache.rs`: the model a saved design keeps.
- `src/expr.rs`, `params.rs`, `inline_params.rs`, `text_params.rs`: expressions with units, the
  parameter table, dependency cycles.
- `src/naming.rs`, `persistent_name.rs` + `persistent_name/`, `history_names.rs`, `lineage.rs`:
  persistent face and edge names that survive upstream edits.
- `src/walk.rs`, `feature_geometry.rs`, `feature_refs.rs`: walks generated by
  `#[derive(sketcraft_derive::Walk)]` on feature fields.
- `src/assembly.rs`, `occurrence_tree.rs`, `joints*.rs`, `motion.rs`: components, occurrences,
  joints, motion studies.
- `src/sheet.rs` (very large), `sheet_*.rs`: sheet metal. `src/drawing.rs`: drawing files.
- `src/appearance*.rs`, `pbr_appearance.rs`, `physical_material.rs`, `render_*.rs`: looks and
  render settings saved in the design.
- `src/format.rs`: the format version, `JSON_STEPS`, history. `src/format/v<N>/`: folded changes.
  `src/format/pending/`: unreleased changes. `src/drawing/format/`: the same for drawings.
- `src/newer_file.rs`: opening a file saved by a newer build without losing what it can't read.
- `build.rs`: lists the `v<N>/` and `pending/` change files into `$OUT_DIR/format_parts.rs`.

## Rules

- No egui/UI and no file I/O outside tests: readers, writers and `safe_write` live in `crates/io`.
  No `unsafe`. The crate root denies `unwrap`/`expect`/`panic!`.
- Design files are hostile input: caps, finite checks, refuse bad shapes before typed decode.
  See `skills/solidcraft-crash-safety/SKILL.md`.
- Changing what a design saves: add ONE file in `src/format/pending/<what-it-is>.rs` (lowercase,
  dashes, `//!` note, optional `pub fn step(v: &mut Value)`). Never edit `FORMAT`, `JSON_STEPS`,
  another change's file or a `v<N>/` folder. Read `src/format/pending/README.md` and
  `skills/solidcraft-file-formats/SKILL.md`. Drawings: `src/drawing/format/pending/`.
- Keep model-specific state (tags, entity assignments) in the document, not in prefs (AGENTS.md).
- Must build for wasm32. Use `web_time` for time.

## Gotchas

- Designs are tagged `"format": "sketcraft/N"`; the legacy `solvecraft/N` tag is still read.
  The skills and READMEs still say `solidcraft/N`.
- `build.rs` asserts `v<N>/` folders are contiguous from 23 and that change file names use only
  lowercase letters, digits and dashes. A bad name fails the build.
- The skills mention `scripts/fold-format-pending.sh` and `docs/design-container.md`; neither is
  in this tree.
